CINDER TRANSIT is a round-based tactical FPS set in an abandoned geothermal foundry interchange. Fight for the core valve as the copper-clad Amber Line or the cool-toned Cobalt Line, buy specialist industrial weapons between rounds, and use rail-car cover to make deliberate shots count.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080
